Crea una aplicación completa en Flutter compatible con Android, Ios, Web y Windows llamada "ProyectoRestaurante" para la gestión integral de un restaurante italiano, utilizando Firebase Authentication (Email/Password y Google) y Cloud Firestore como backend. La aplicación debe implementar un sistema de roles (RBAC) con un Panel de Administrador exclusivo y funcionalidades de gestión, junto con el CRUD completo (crear, leer, actualizar, borrar) para las 15 entidades basadas en el diagrama proporcionado: Roles, Empleados, Clientes, Mesas, Categorias, Platillos, Ingredientes, Proveedores, Reservaciones, Pedidos, Detalle_Pedido, Pagos, Compras, Detalle_Compra y Recetas. Utiliza una arquitectura por características (lib/features/[entidad]/data|domain|presentation), Riverpod para el manejo de estado, GoRouter para la navegación y una interfaz moderna con paleta de colores italiana, entregando el código fuente completo de todas las capas (modelos, repositorios, providers, pantallas y widgets), las dependencias en pubspec.yaml y un script ejecutable enviargithub.dart en la raíz que automatice la inicialización del repositorio y la subida del código a GitHub.
